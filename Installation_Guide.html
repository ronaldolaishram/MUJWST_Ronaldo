🚀 Installation Guide

JWST COSMOS-Web Data Analysis Workshop

ICARD, Manipur University | November 5, 2025

📋 Before You Start: This guide will help you set up a Python environment for the workshop. Choose the method that works best for you: Conda (recommended) or pip.

Prerequisites

You need one of the following installed on your computer:

  • Anaconda or Miniconda (Recommended for beginners)
  • Python 3.9+ with pip (Alternative method)
⚠️ Important: Make sure you have at least 2 GB of free disk space for the environment and packages.

Option 1: Using Conda (Recommended)

Conda is the easiest way to manage Python environments and packages for scientific computing.

  1. Open Terminal/Command Prompt

    • Windows: Open "Anaconda Prompt" from Start Menu
    • Mac/Linux: Open Terminal

  2. Navigate to Workshop Directory

    Change to the directory where you saved the workshop files:

    # Replace with your actual path cd /path/to/DAY2

  3. Create Conda Environment

    Create a new environment using the provided environment.yml file:

    conda env create -f environment.yml

    This will create an environment named jwst-cosmos-workshop with all required packages. It may take 5-10 minutes.

  4. Activate the Environment

    conda activate jwst-cosmos-workshop

    You should see (jwst-cosmos-workshop) appear in your terminal prompt.

  5. Verify Installation

    Test that everything is working:

    python -c "import numpy, scipy, matplotlib, astropy; print('All packages installed successfully!')"

  6. Launch Jupyter Notebook

    jupyter notebook

    This will open Jupyter in your web browser. Navigate to the workshop notebooks and you're ready!

✅ Success! You're all set! Your environment is ready for the workshop.

Option 2: Using pip (Alternative)

If you don't have Conda, you can use pip to install packages in a virtual environment.

  1. Open Terminal/Command Prompt

    Open your system's terminal or command prompt.

  2. Navigate to Workshop Directory

    cd /path/to/DAY2

  3. Create Virtual Environment

    # Create virtual environment python -m venv jwst-workshop-env # Activate it (Mac/Linux) source jwst-workshop-env/bin/activate # Activate it (Windows) jwst-workshop-env\Scripts\activate

  4. Install Required Packages

    pip install -r requirements.txt

    This will install all necessary packages. It may take 5-10 minutes.

  5. Verify Installation

    python -c "import numpy, scipy, matplotlib, astropy; print('All packages installed successfully!')"

  6. Launch Jupyter Notebook

    jupyter notebook

Quick Start Commands

For Conda Users:

# Every time you start working conda activate jwst-cosmos-workshop jupyter notebook # When you're done conda deactivate

For pip Users:

# Every time you start working (Mac/Linux) source jwst-workshop-env/bin/activate jupyter notebook # Every time you start working (Windows) jwst-workshop-env\Scripts\activate jupyter notebook # When you're done deactivate

Troubleshooting

Problem: "conda: command not found"

Solution: You need to install Anaconda or Miniconda first.

  • Download from: anaconda.com/download
  • Or Miniconda: docs.conda.io/en/latest/miniconda.html

Problem: Package installation fails

Solution: Try these steps:

  1. Update conda: conda update conda
  2. Clear cache: conda clean --all
  3. Try again: conda env create -f environment.yml

Problem: Jupyter notebook won't start

Solution: Make sure the environment is activated:

conda activate jwst-cosmos-workshop jupyter notebook

Problem: Import errors in notebooks

Solution: Verify all packages installed correctly:

conda list

Check that numpy, scipy, matplotlib, and astropy are in the list.
